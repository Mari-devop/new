🎯 Проблема

(то воно видумано/ прогнозоване що так може бути)

Поточна ситуація: Менеджери втрачають час на відстеження коли прийдуть аналізи, не бачать загальної картини роботи всіх своїх кампаній (чи запам'ятовують), а керівництво не має прозорості в процесах своїх менеджерів.

❌ Втрата часу на пошук інформації в адмінці
❌ Відсутність єдиної картини роботи
❌ Складність звітності (треба робити вручну)
❌ Пізнє чи ручне виявлення проблем

💡 Рішення

Runbook CATTIX — це єдина панель відстеження для всіх аналізів та таск менеджер для планування своєї роботи

📊 Автоматичне відстеження

Збирає всі події з CATTIX автоматично

📅 Розумне планування

Показує що треба зробити сьогодні

📈 Прозора звітність

Готові звіти для клієнтів та керівництва

🚨 Швидке виявлення проблем

Підсвічує затримки та збої

🚨 Надання звітності роботи Cattix менеджера - клієнту

Прямий лінк зі звітності по роботі менеджера - по компанії клієнта

⚙️ Як це працює

1

Збір подій

Автоматично отримуємо всі події з CATTIX:

Авто: scheduled → started → ready → applied Ручні: manual_scheduled → started → ready → applied
2

Аналіз та планування

Система аналізує події та створює план роботи:

  • 📋 Today — що треба зробити сьогодні
  • 📅 Calendar — майбутні аналізи
  • 📊 Changes — історія всіх змін
3

Звітність

Автоматично генерує звіти:

  • 📄 PDF звіти по днях/тижнях/місяцях
  • 💬 Дайджести в Slack/Email
  • 🔗 Посилання для швидкого доступу

🔧 Основні можливості

📅 Календар

Всі майбутні аналізи в одному місці

  • Автоматичні та ручні аналізи
  • Фільтри: клієнт, кампанія, тип
  • Статуси: Upcoming, Due, Overdue

📋 Сьогоднішні завдання

Що треба зробити прямо зараз

  • Пріоритетні завдання
  • Затримки та ескалації
  • Швидкі дії

  • Статус виконання
  • Обсяг роботи (ETA)
  • Прямий лінк в CATTIX
